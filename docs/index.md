Reusable AI skills for learning, studying, and getting consistent results from any assistant.

MindScrape publishes **structured instruction sets** — plain markdown skills you can copy into Cursor, Claude Projects, ChatGPT workflows, or any tool that supports reusable prompts.

---

## Available skills

### [Summarise](skills/summarise.html)

Upload a PDF or DOCX and receive a faithful, structured summary in the same language as the source document.

- **Formats:** PDF, DOCX
- **Modes:** Short (default), Long
- **Best for:** Textbooks, lecture notes, research papers

[View full documentation →](skills/summarise.html)

## Get started

1. Browse the [skills directory on GitHub](https://github.com/mindscrape9/skills/tree/main/skills).
2. Read each skill's `README.md` for usage and options.
3. Copy the skill folder — including `SKILL.md` — into your AI tool.
4. Invoke the skill by name in a new conversation.

## Philosophy

- Solve one problem well
- Produce consistent outputs
- Minimize hallucinations
- Preserve user intent
- Be easy to read and modify
