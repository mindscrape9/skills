# Skills

Each subdirectory is a standalone MindScrape skill you can download and use independently.

| Skill | Description |
|-------|-------------|
| [summarise](summarise/) | Faithful PDF/DOCX summaries with page references |

## Folder layout

Every skill includes:

| File | Audience | Purpose |
|------|----------|---------|
| `SKILL.md` | AI agent | Instructions your assistant follows |
| `README.md` | Humans | Usage guide, options, examples |

Copy the whole skill folder into your AI tool's skills directory.
